# Rewrite Docs

This directory is the canonical planning surface for rebuilding `dotheyplaytoday` from the current prototype.

- `spec.md` defines the product, domain model, behavior, and v1 boundaries.
- `GLOSSARY.md` defines canonical project language and concept relationships.
- `prototype-lessons.md` captures what the prototype proved and what became accidental complexity.
- `effect-v4-and-engineering-practices.md` records source-derived implementation practices for the fresh build.
- `rebuild-plan.md` lays out the concrete phased rebuild sequence.
- `task-plan.md` splits the rewrite into sequential branch-sized implementation tasks.

The prototype code is useful evidence. It is not the source of truth for the rewrite unless these docs explicitly carry the idea forward.
